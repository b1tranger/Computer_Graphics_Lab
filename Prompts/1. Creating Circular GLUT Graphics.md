**No, using a `for` loop with `cosf`/`sinf` is NOT the only way to draw a circle!**

---

### Why does OpenGL use loops for circles?
In OpenGL, there is no built-in command like `glDrawCircle()`. OpenGL only knows primitive shapes: `GL_POINTS`, `GL_LINES`, `GL_TRIANGLES`, `GL_QUADS`, and `GL_POLYGON`. 

To draw a circle in OpenGL, graphics hardware renders a polygon with many small sides (e.g. 36 or 100 sides). We use a `for` loop so we don't have to manually write out 100 lines of `glVertex2f` coordinates.

---

### Can it be done with simple lines like `cgm lab-3.1/main.cpp`?

**Yes!** You can use `GL_POLYGON` or `GL_LINE_LOOP` and write out individual `glVertex2f` points directly around the perimeter, exactly like you do for triangles and quads:

#### 1. Manual Direct Vertices Syntax (Octagon Circle)
```cpp
// Direct manual syntax (similar to cgm lab-3.1/main.cpp)
glBegin(GL_POLYGON);
    glColor3f(1.0f, 0.2f, 0.2f); // Red
    glVertex2f( 0.00f,  0.30f); // Top
    glVertex2f( 0.21f,  0.21f); // Top-Right
    glVertex2f( 0.30f,  0.00f); // Right
    glVertex2f( 0.21f, -0.21f); // Bottom-Right
    glVertex2f( 0.00f, -0.30f); // Bottom
    glVertex2f(-0.21f, -0.21f); // Bottom-Left
    glVertex2f(-0.30f,  0.00f); // Left
    glVertex2f(-0.21f,  0.21f); // Top-Left
glEnd();
```

---

#### 2. Simple Degree-Based Loop (`0` to `360` degrees)
If you want a smoother circle without hardcoding points manually, you can also write a simple loop from `0` to `360` degrees:

```cpp
glBegin(GL_POLYGON);
    glColor3f(0.2f, 0.6f, 1.0f);
    for (float angle = 0.0f; angle < 360.0f; angle += 5.0f) {
        float rad = angle * (3.14159f / 180.0f); // convert degrees to radians
        float x = cx + radius * cos(rad);
        float y = cy + radius * sin(rad);
        glVertex2f(x, y);
    }
glEnd();
```

---

#### 3. Midpoint Circle Algorithm (Classic Lab Algorithm with `GL_POINTS`)
In Computer Graphics courses, you will also learn **Midpoint / Bresenham's Circle Algorithm**, which calculates 8 octant points using pixel increments:

```cpp
glPointSize(3.0f);
glBegin(GL_POINTS);
    glColor3f(1.0f, 1.0f, 0.0f);
    // Plot 8 symmetrical points per pixel step...
glEnd();
```
